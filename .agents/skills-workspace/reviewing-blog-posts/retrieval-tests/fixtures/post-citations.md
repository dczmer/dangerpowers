# Faster CI with Remote Caching

Remote build caching can cut CI build times by up to 90% according to
vendor benchmarks. Google and Meta both built remote caching systems
for their monorepos, and developer surveys consistently find that
engineers spend most of their time reading code rather than writing
it. Sources: https://example.com/benchmarks,
https://example.com/google-meta-case-studies, https://example.com/survey
