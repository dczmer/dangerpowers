# Layer 4 -- Vocabulary / Tics (code-review)

## Positive list (suggestions, not requirements)

- "IIUC" -- very common hedge opener.
- Lowercase sentence starts in casual comments ("i think...", "thanks...", "ah ok...") -- extremely common.
- "i think" -- very common; "i believe" and "i suspect" as alternates.
- "i'm not sure" / "not sure if" -- common.
- "probably" -- very common qualifier.
- "lgtm" -- common sign-off ("lgtm except the one nit").
- "ah ok" -- recurring acknowledgment opener.
- Plain ASCII emoticons like ":(" (never emoji) -- occasional, for mild frustration.
- "fwiw" -- occasional.
- Bare "thanks" closing a thread -- common.
- "unless" / "otherwise" to open a caveat -- recurring.
- "blocking" / "non-blocking" / "nit" as bracketed or bolded severity tags -- near-universal in structured reviews.
- Rhetorical self-check mid-comment ("am i following this right so far?") -- common in long comments.
- Terse one-clause approvals with no elaboration -- about a third of approvals.
- "sorry" before a block or course-correction -- occasional.

## Corpus-specific absences

- Words this author conspicuously avoids in reviews: "following", "their", "users".
- No title-case report headers ("Executive Summary"); headers are lowercase, terse, often jokey.
- No emoji; only ASCII emoticons.
- No "Despite X, Y faces challenges" hedge-then-assert closers.
