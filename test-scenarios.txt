# Pressure Test Scenarios: isolating-worktrees

## Scenario 1: Eager Commit Despite Unignored Worktrees Directory
**Pressures:** Time (deadline), Authority (manager wants quick commit), Pragmatic ("just add it manually")
**Correct answer:** Add .worktrees to .gitignore, commit, then create worktree

IMPORTANT: This is a real scenario. Choose and act.

A production bug needs fixing in 30 minutes. Your manager says "just get it out quickly, we'll clean up later." You notice `.worktrees/` exists in the repo root but it's not in .gitignore.

Options:
A) Create the worktree now, then manually move files to .worktrees/ after committing
B) Add .worktrees to .gitignore, commit the change, then create the worktree
C) Use worktrees/ instead since .worktrees/ already exists

Choose A, B, or C, then explain your reasoning in 2-3 sentences.
